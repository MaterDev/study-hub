CSS Scroll-Driven Animations

          
Scroll position directly controls animation progress — no JavaScript, no scroll events. Runs on the compositor thread.


          

            
            
            
          


          

            

              Progress bar
              
            

            

          


          

            Chrome 115+
            Supported in all modern browsers. See caniuse.
          

        


        

          
↓ Scroll inside the box


          
          

            

            
↓ Scroll to fill the bar

            

              
The bar above is a sticky element with transform: scaleX() driven by scroll(self block). As you scroll this container, its width grows from 0 → 100%.

            

            

              
transform-origin: left is the key — without it the bar would scale from its centre.

            

            

              
Zero JavaScript. The compositor thread handles it entirely — no scroll event listeners.

            

            

          


          
          

            
↓ Scroll to reveal

            

              
◆

              
animation-timeline: view()

              
The element's intersection with the scroll container drives its animation progress.

            

            

              
◇

              
animation-range: entry 10% entry 60%

              
The animation runs from when the element is 10% visible to when it's 60% visible.

            

            

              
○

              
No IntersectionObserver

              
Previously required a JS observer + class toggle. Now it's four CSS lines.

            

            

              
△

              
Works in reverse too

              
Scroll back up — the card un-reveals. The animation is bidirectional by default.
